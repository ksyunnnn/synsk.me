Implementation Notes

  • ノイズテクスチャ: SVG feTurbulence フィルターをインライン data URI で適用
  • 質量感: 複数レイヤーの box-shadow（内側ベベル + 多段ドロップシャドウ）
  • 埃の質感: mix-blend-mode: screen + 低 opacity のノイズ
  • ホバー: 微妙な translateY と rotate で「持ち上がる」感覚
