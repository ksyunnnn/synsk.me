# OOUI の 3 段階

出典: 上野学「OOUI – オブジェクトベースのUIモデリング」（ソシオメディア、2016-12-08） https://www.sociomedia.co.jp/7279 の「オブジェクトベースUIのモデリング方法」

## 1. オブジェクトとスコープ

- ユーザーが意識する名詞を選ぶ。動詞（やること）を入口にしない
- オブジェクトかどうかの判断: 「同じ属性（プロパティ）を持った複数のものがある」「それらに対して共通の処理（アクション）を行える」
- 1 つしかないもの、値が少なく決まっているものは、オブジェクトではなく属性か絞り込みの軸にする
- 範囲の外に置くものを書く

## 2. ビュー

- オブジェクトごとに、コレクション（複数を並べ、重要な属性だけ出す）とシングル（1 件を多くの属性で出す）を決める
- 1 つのオブジェクトは複数のビューを持てる（表と時系列など）
- 別のものを探す手がかりでしかないオブジェクトは、シングルを表に出さなくてよい

## 3. アクションとインタラクション

- 広い画面ではビューをペインに並べ、「左で選ぶと右に出る」の向きにする
- 狭い画面では同じモデルのまま画面の単位を変える
- 要件は、画面の遷移順ではなく、ビューの表現とアクションで満たす

## 書き方の型

```
### 1. オブジェクトとスコープ
- <オブジェクト>: …
- 関係: …
- 範囲外: …

### 2. ビュー
| オブジェクト | コレクション | シングル |

### 3. アクションとインタラクション
- …

### 未決
- …
```
