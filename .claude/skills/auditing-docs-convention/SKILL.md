# ドキュメント規約の監査

記録がドキュメント規約から外れていないかを、根拠付きで示す。

## 手順

Agent ツールで `docs-convention-auditor` を起動する。

```
subagent_type: docs-convention-auditor
prompt: |
  ドキュメント規約への適合を監査してください。

  範囲: {{差分 | 全体}}
  対象ファイル: {{パスの列挙。全体のときは「全体」}}
  直前の変更: {{変更点}}
```

`{{変更点}}` は、直前に何を追加・変更したかの1〜3行。

範囲は既定が差分。ユーザーが全体を指定したときだけ全体にする。差分の対象ファイルは `git diff --name-only origin/main...HEAD` で取る。

**自分で監査しない。** 成果物を書いた者が検査すると、その盲点がそのまま検査の盲点になる。手順と観点は監査人の定義（`.claude/agents/docs-convention-auditor.md`）が持つ。

## 報告を受けたら

3つに分ける。

- **成果物の違反** — 直す
- **基準の欠陥** — 基準を直す。**全文書が違反する規定は、規定側が誤っている**
- **判断保留** — ユーザーへ渡す

基準の欠陥を成果物の違反として直さない。基準に従うほど基準に違反する状態が、実際に起きる。

## 直したら、もう一度監査する

修正の過程で新しい違反が生まれる。参照していた記述を消す、根拠を空にする、重複を作る。
